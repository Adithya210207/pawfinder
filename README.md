# 🐾 PawFinder — Animal Adoption & Rescue Platform

PawFinder is an all-in-one animal welfare and pet adoption web platform connecting animal lovers with stray dogs, shelter animals, emergency rescue helplines, foster programs, and pet care educational resources across India.

---

## 🌐 Live Web Application

👉 **[https://pawfinder-xvjk.onrender.com/](https://pawfinder-xvjk.onrender.com/)**

---

## 🌟 Key Features

- 🐶 **52 Dog Profiles**: Detailed profiles with photos, age, breed, gender, personality tags, health records, and adoption status.
- 🏥 **18 Partner Shelters**: Filterable shelter directory with contact details, available dogs count, and interactive shelter chat.
- 📚 **26 Pet Care & Awareness Articles**: Educational guides covering stray dog welfare, medical emergency response, nutrition, and training tips.
- 🚑 **Emergency Helpline & Rescue Portal**: Quick-call emergency hotlines and rescue report submission.
- 🤝 **Foster & Volunteer Network**: Online registration for temporary pet fostering and local volunteer events.

---

## 💻 Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla design system with dark mode & dynamic micro-animations), JavaScript (ES6+).
- **Backend & Database**: Node.js / Express web server with fallback database engine.
